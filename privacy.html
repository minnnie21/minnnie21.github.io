YoutubePearl 개인정보처리방침

시행일: 2026년 11월 12일

1. 수집하는 정보

YoutubePearl은 사용자가 직접 승인한 YouTube 채널에 대해 아래 정보를 읽기 전용으로 조회합니다.

  • 채널 정보: 채널명, 채널 ID, 구독자 수, 누적 조회수, 영상 수
  • 영상 정보: 제목, 게시일, 길이, 공개 상태, 조회수, 좋아요 수, 댓글 수
  • 분석 정보: 시청 시간, 평균 시청 지속 시간, 구독자 증감, 라이브 동시 시청자 수, 노출수 및 클릭률

사용 권한(스코프): youtube.readonly, yt-analytics.readonly

2. 이용 목적

조회한 정보는 사내 YouTube 채널 성과 분석 및 내부 보고 목적으로만 사용합니다.

3. 보관 및 공유

  • 데이터는 회사의 Google Workspace 스프레드시트에 저장되며, 접근 권한이 있는 담당자만 열람할 수 있습니다.
  • 수집한 데이터를 제3자에게 판매하거나 제공하지 않으며, 광고 목적으로 사용하지 않습니다.
  • 업무상 더 이상 필요하지 않은 데이터는 삭제합니다.

4. YouTube API 서비스 이용 안내

본 도구는 YouTube API 서비스를 사용합니다. 본 도구를 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google의 데이터 처리에 대해서는 Google 개인정보처리방침을 참고하세요.

본 도구의 Google API 데이터 사용은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 권한 철회

언제든지 Google 계정 → 서드 파티 연결에서 YoutubePearl의 접근 권한을 철회할 수 있습니다. 브랜드 계정은 해당 브랜드 계정으로 전환한 뒤 철회하세요.
